# Lab 2: ALU Transcript Generator & Organizer

## Overview
This project contains a Python application to evaluate student academic standing from a CSV file of grades, and a Bash shell script to automate file archiving and logging.

## Files Included
- `grade-evaluator.py`: Validates grades, calculates GPA, determines pass/fail status per category, and suggests resubmission options.
- `organizer.sh`: Automatically archives current grades with a timestamp, resets a blank `grades.csv`, and logs actions.
- `grades.csv`: Source dataset for course grades.
- `organizer.log`: Log file generated by the shell script.
